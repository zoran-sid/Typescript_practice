# Day 20 参考答案与记忆卡

## 01：as 不会改变数据

原始 `age` 是字符串。断言成 `User` 后，它仍然是字符串，所以 `+ 1` 得到的是拼接。答案先解析成 `unknown`，再验证每个字段。

## 02：类型谓词不能说谎

`value is Product` 是你给编译器的保证。保证里写了 `price: number`，就必须真的检查 `price`。

## 03：嵌套数据逐层检查

顺序是：外层对象 → `contact` 对象 → `email` 字符串 → `skills` 数组 → 每个技能都是字符串。少一层都可能在运行时出错。

## 04：把失败原因保留下来

先单独捕获 JSON 语法错误；解析成功后再验证字段。判别联合让调用者必须分别处理成功和失败。

记忆卡：

- 边界数据：先 `unknown`；
- 类型断言：不验证、不转换；
- 类型谓词：检查必须配得上承诺；
- 编译通过：不等于运行数据可信。

间隔复习：两天后不看答案重写 `isProduct` 和 `isProfile`。
