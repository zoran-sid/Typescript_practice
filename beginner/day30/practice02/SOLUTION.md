## 方案一：以最小声明适配旧模块

### 搭建顺序

1. 核对旧 JavaScript 的导出形式、参数顺序和真实返回类型。
2. 保留两段同名接口以练习合并，并建立现代状态值与类型。
3. 在入口中创建符合合并接口的值并调用旧模块。

### 类型与数据流

旧模块行为 → `.d.ts` 描述 → 合并后的类型 → TypeScript 调用点。

### 关键自检点

- 默认导出与具名导出的声明语法必须匹配实际模块。
- 不要为了消除报错把真实返回值写成更方便但错误的类型。
