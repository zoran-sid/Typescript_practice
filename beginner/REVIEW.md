# 间隔复习与拓展思考

每天现在只有一道完整练习。它比多个半成品更需要主动回忆：你必须自己决定声明什么、按什么顺序处理、在哪里分支，以及如何输出。

## 每天开始前的 8–10 分钟

1. 不看笔记，口述昨天最重要的两个概念。
2. 在纸上或临时文件中写出昨天练习的程序结构，不必逐字复原。
3. 回答三天前课程的拓展思考题。
4. 从七天前选一个易错点，换一组输入预测结果。
5. 把仍然说不清的内容写入错题记录。

## 推荐复习间隔

| 时间 | 做什么 |
| --- | --- |
| 当天 | 从空白完成 practice，并解释错误原因 |
| +1 天 | 不运行代码，先写出完整步骤或伪代码 |
| +3 天 | 换一组输入，再写一个最小版本 |
| +7 天 | 回答拓展思考，并联系当前课程 |
| +14 天 | 从空白重写核心函数，不看答案 |

## 怎样重新练习

- 保留已经完成的 `practice.ts` 作为学习记录。
- 复习时新建一个临时 `.ts` 文件，重新从空白写核心部分。
- 也可以先清空自己的实现，但不要复制 `solution.ts`。
- 当前文件可直接右击 **Run Code**。
- 命令行备用方式是 `npm run beginner -- day10`。

拓展思考题不追求唯一答案。先给出自己的理由，再查看 `SOLUTION.md` 的参考方向；理由比结论更重要。
