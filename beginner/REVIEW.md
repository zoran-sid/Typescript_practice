# 间隔复习与拓展思考

每天有 1–3 道互相独立的完整练习。复习时不要只重跑已经会的那一题：先看变量关联数据流回忆每个值从哪里来、流向哪里，再进入另一个 practice 目录从空白重写。不同场景会迫使你重新判断声明、处理顺序、分支与输出。

## 每天开始前的 8–10 分钟

1. 不看笔记，口述昨天最重要的两个概念。
2. 在纸上或临时文件中写出昨天练习的程序结构，不必逐字复原。
3. 回答三天前课程的拓展思考题。
4. 从七天前选一个易错点，换一组输入预测结果。
5. 把仍然说不清的内容写入错题记录。

## 推荐复习间隔

| 时间 | 做什么 |
| --- | --- |
| 当天 | 从空白完成一个 practiceXX，并解释错误原因 |
| +1 天 | 不运行代码，先写出完整步骤或伪代码 |
| +3 天 | 换一组输入，再写一个最小版本 |
| +7 天 | 回答拓展思考，并联系当前课程 |
| +14 天 | 从空白重写核心函数，不看答案 |

## 怎样重新练习

- 保留各个 `practiceXX/practice.ts` 作为独立学习记录。
- 复习时优先进入同一天另一道 practice；不要导入已经完成的代码。
- 先遮住代码，只看练习数据流口述每个变量的来源、分支、中间结果和输出。
- 当前练习文件可直接右击 **Run Code**。
- 命令行备用方式是 `npm run beginner -- day10 practice02`。

拓展思考题不追求唯一答案。先给出自己的理由，再查看 `docs/dayXX/practiceXX/SOLUTION.md` 的参考方向；理由比结论更重要。
