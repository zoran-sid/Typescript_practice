## 方案一：把浏览器、网络和 CLI 都压缩成可测试边界

### 搭建顺序

1. 为事件和 JSON 客户端声明最小接口，不让核心函数依赖完整运行环境。
2. 事件读取处理空目标；网络响应从 `unknown` 经守卫得到课程或失败值。
3. CLI 参数先查找标志后的文本，再转换并校验为最终选项。

### 类型与数据流

环境输入 → 最小接口/字符串数组 → 边界函数 → 已验证普通值 → 输出。

### 关键自检点

- 事件目标、标志后的值和网络字段都可能缺失。
- 默认参数只用于真正缺省的情况，非法显式输入不能悄悄冒充默认值。
