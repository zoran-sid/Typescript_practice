# 学习进度表

建议每周学习 4–5 天，其余时间只做短复习。一天 60–90 分钟已经足够；如果某天四题做不完，可以拆成两次，不必赶进度。

每完成一天，勾选“课程”和“+1 复习”。三天、七天后再回来勾选对应格。

## 主线毕业自检

- [ ] Day 00–26 的示例与完整参考答案通过 `npm run beginner:verify -- day26` 及全量验证。
- [ ] 能独立完成 Day 26 四道题。
- [ ] 能解释类型擦除、运行时验证和自动测试的区别。
- [ ] 能在不修改输入的情况下更新一项嵌套业务数据。
- [ ] 能从 `unknown` 开始验证外部数组。
- [ ] 能用联合表达加载、成功、失败状态。
- [ ] 能读懂第一条 TypeScript 错误，而不是立即加入 `as any`。
