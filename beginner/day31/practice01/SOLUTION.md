## 方案一：分别处理惰性序列、迭代器状态和大整数边界

### 搭建顺序

1. 保留偶数生成器，让循环按需 `yield`，不要预先建立结果数组。
2. 在 countdown 的迭代器工厂内部保存独立状态，并正确区分尚有值与完成。
3. 大整数运算全程使用 bigint，进入 JSON 前再转换为可序列化形式。

### 类型与数据流

输入范围 → generator/iterator → 消费者逐次拉取；bigint → 运算 → 字符串 → JSON。

### 关键自检点

- 每次请求下一个值时才推进状态，同一 iterable 的不同 iterator 不应共享游标。
- number 与 bigint 不能直接混算，JSON 也不能直接序列化 bigint。
