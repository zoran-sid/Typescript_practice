## 方案一：把任务转换链拆成可复用的业务步骤

### 搭建顺序

1. 先从共享模型创建固定原始任务。
2. 用命中 id 的结果生成报告，同时读取原数组与新数组验证旧数据未被污染。
3. 再传入不存在的 id，逐项比较对象引用，确认没有任务被替换。

### 类型与数据流

任务输入 → `map` 更新 → `filter`/排序 → 聚合统计 → 输出。

### 关键自检点

- 不要只复制数组后继续修改其中共享的任务对象。
- 没有命中时仍可能返回新数组，但每个未变化任务可以保持原引用；两种比较不要混为一谈。
