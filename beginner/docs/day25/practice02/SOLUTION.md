## 方案一：把任务转换链拆成可复用的业务步骤

### 搭建顺序

1. 先从共享模型创建固定原始任务。
2. 分别完成不可变状态更新、条件筛选、时长排序和状态统计的 TODO。
3. 输出时同时读取原数组和新数组，以验证旧数据未被污染。

### 类型与数据流

任务输入 → `map` 更新 → `filter`/排序 → 聚合统计 → 输出。

### 关键自检点

- 不要只复制数组后继续修改其中共享的任务对象。
- 每个回调都要返回当前位置应进入下一步的值。
