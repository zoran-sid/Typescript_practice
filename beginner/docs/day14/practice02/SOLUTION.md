## 方案一

1. 逐个查看三个辅助模块：先区分类型、默认值、具名值和默认函数。
2. 类型使用 `import type`；数据模块的具名仓库名在导入处改成本地别名。
3. 让默认商品进入 `Product` 约束，再把它的价格和完整对象分别交给两个工具。
4. 入口只拼装结果，不重新实现价格或库存规则。

## 关键检查点

- 默认导入写在花括号外，具名导入及 `as` 别名写在花括号内。

- `Product` 只参与检查；仓库、商品和两个函数都必须在运行时存在。

- NodeNext 源码相对路径仍写 `.js`。
