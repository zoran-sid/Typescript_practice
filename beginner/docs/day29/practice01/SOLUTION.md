## 方案一：从现有结构逐层派生类型，而不是重写

### 搭建顺序

1. 先为配置、事件和标识符保留源类型。
2. 分别完成映射、条件推断、键重映射和品牌类型的 TODO。
3. 在少量值声明中验证派生类型，再由构造函数守住品牌值入口。

### 类型与数据流

源类型 → 类型运算 → 派生类型 → 受检查的值；外部字符串 → 验证 → 品牌值。

### 关键自检点

- 类型运算只发生在编译期，品牌构造仍需真正的运行时验证。
- 键重映射后，处理器参数必须继续对应原事件负载。
