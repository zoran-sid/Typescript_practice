## 直接调用逻辑

1. `FeatureConfig` 经 `Flags` 派生出同键布尔对象，固定 `flags` 提供第一行输出。
2. `topics` 经 `ElementOf` 提取单项类型，`selected` 只能使用其中一个字面量。
3. 固定负载分别进入 `handlers.onReady` 与 `handlers.onFailed`，回调读取对应字段后输出。
4. 普通字符串先进入 `createUserId` 验证，通过后成为 `UserId`，再进入 `profilePath` 返回路径。

代码中的 `// 调用关系：` 注释标出了固定数据进入函数、返回值进入下一步以及最终输出的位置。顺着这些注释阅读，就能把函数声明和真正发生的调用连起来。
