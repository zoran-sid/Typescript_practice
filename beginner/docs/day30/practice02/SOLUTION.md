## 方案一：类型增强与运行时补丁成对交付

### 搭建顺序

1. 先用模块命名空间导入读取旧计分模块，核对 `.js` 与 `.d.ts` 的导出。
2. 在任何补丁之前观察 `LegacyUser.prototype.label`，保存真实运行时结果。
3. 用模块增强补实例成员的类型，再给原型安装同名函数；最后创建实例调用。

### 类型与数据流

旧模块 → 模块对象；旧类原型 → 补丁前观察；模块增强 + 原型实现 → 可调用实例方法。

### 关键自检点

- 模块增强只改编译器看到的成员，原型赋值才改变运行时对象。
- `import * as` 是 ES 模块导入语法；不要把它解释成旧式 TypeScript `namespace`。
