## 方案一

1. 先检查 SKU 是否存在以及 `nextQuantity` 是否为负数；拒绝分支直接交回原购物车。
2. `0` 分支用 `filter` 生成不含目标商品的新数组。
3. 正数分支用 `map`，只为目标商品创建数量不同的新对象。
4. 数量操作完成后再用对象 spread 添加优惠券，最后对照读取新旧购物车。

## 关键检查点

- 先判断分支，再创建需要的新容器；拒绝操作不应伪装成一次成功更新。

- `map` 和 `filter` 都返回新数组，但目标不同：一个替换元素，一个删除元素。

- 原购物车中的键盘数量必须保持 `2`。
