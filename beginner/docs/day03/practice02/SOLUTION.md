## 为什么这次需要数组下标

本题最后要报告位置。`minutes` 只告诉你“这一项耗时多少”，`index` 才告诉你“这一项在数组哪里”。因此循环中同时保留两者：

```text
index ──> taskMinutes[index] ──> minutes
  │                              │
  └── + 1 ──> 给人看的序号       └── 与边界比较
```

只有比较结果为 `true` 时，才增加计数并把序号接到结果文字后面。

## 常见错误示例

```ts
slowPositionsText = slowPositionsText + index;
```

代码下标从 0 开始，这会得到 1 和 3；业务要的是“第 2、4 个任务”，所以拼接前要完成下标到序号的转换。还要处理分隔符，否则两个序号会粘成 `"24"`。

```ts
if (minutes > slowBoundary) {
  // ...
}
```

这会漏掉刚好 10 分钟的任务。题目说“达到 10 分钟”，边界值也属于慢任务。
