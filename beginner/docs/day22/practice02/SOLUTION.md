## 方案一：成功规则走案例表，失败规则单独断言

### 搭建顺序

1. 先完成 `shippingFee` 的输入错误、免运费、会员、普通用户四条分支。
2. 把三条有返回值的规则放进 `ShippingCase[]`，循环中统一执行 Arrange、Act、Assert。
3. 负金额使用只接受 `RangeError` 的独立断言；最后输出真正通过的数量。

### 类型与数据流

案例项 → `shippingFee` → 实际运费 → 相等断言；负金额 → `RangeError` 断言。

### 关键自检点

- 案例循环不能无条件累加，断言失败时必须在累加前停止。
- 异常断言要区分“预期的 RangeError”“其他错误”“完全没有错误”。
