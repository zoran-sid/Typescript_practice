## 方案一：以购物车纯函数为中心安排回归测试

### 搭建顺序

1. 保留 `cartTotal`、同步断言、异常断言和异步示例的主要签名。
2. 先写正常数量，再写边界与非法数量，最后验证异步问候结果。
3. 测试输入、实际值、期望值分别命名，避免把期望输出写进业务函数。

### 类型与数据流

`price` 与 `quantity` → `cartTotal` → 实际总价 → 断言；非法输入 → 异常断言。

### 关键自检点

- 异常断言在 action 没有抛错时也必须失败。
- 业务函数用 `return` 交付结果，`console.log` 只显示测试结论。
