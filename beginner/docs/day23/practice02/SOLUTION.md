## 方案一：把严格配置翻译成可观察的代码规则

### 搭建顺序

1. 按题目列出的严格选项建立说明项，但先保留每项解释的 TODO。
2. 让每条说明连接到一个具体风险：未检查索引、可选属性或 catch 中的未知值。
3. 按要求的顺序输出配置名称与说明。

### 类型与数据流

TSConfig 选项 → 对应风险 → 处理原则 → `configNotes` → 输出。

### 关键自检点

- 不要通过关闭严格选项解决示例错误。
- 先修第一条根因错误，再观察后续错误是否仍然存在。

完成 TODO 后，请以本题 README 的精确输出和限制逐项自检；不要把显示结果直接写死。
