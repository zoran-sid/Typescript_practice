# Day 04 参考答案说明

先自己修改 `practice-XX.ts`。答案文件用于核对思路，不要把“看懂”误当成“会写”。

## 01 范围与逻辑组合

温度要同时满足下限和上限，所以两个范围条件之间用 `&&`。最后还要满足“没有下雨”，写成 `!isRaining`。

## 02 边界

题目说 60 分“也算”及格，因此两个位置都必须使用 `>= 60`。只修其中一个，输出仍会互相矛盾。

## 03 字符串转数字

`quantityText` 是字符串。`Number(quantityText)` 得到数字后，乘法和大小比较才表达清楚的数值规则。

## 04 分支优先级

先检查满 200 的最高优惠，再检查会员条件，最后检查优惠券。会员门槛包含 100，所以要写 `>= 100`。

npm run beginner:solution -- day04 04
