# Day 08 参考答案说明

`contacts` 的类型明确说明电话、地址和地址中的城市都可能缺失。`find` 的结果也可能是 `undefined`，因此三个显示值都从 `selectedContact?.` 开始安全访问。

城市需要经过两层可选链：先确认联系人存在，再确认 `address` 存在，最后读取 `city`。任意一层缺失都会得到 `undefined`，然后由 `?? "未填写"` 提供默认文字。

`score` 的值 0 和 `nickname` 的值空字符串都不是缺失值，所以 `??` 会原样保留。`JSON.stringify("")` 让终端清楚显示两个引号，方便确认空字符串确实存在。

## 拓展思考参考方向

逻辑或 `||` 根据值是否“truthy”选择结果，数字 0 属于 falsy，因此会错误使用右侧 100。空值合并 `??` 只把 `null` 和 `undefined` 视为缺失，0 是明确保存的有效数字，所以被保留。
