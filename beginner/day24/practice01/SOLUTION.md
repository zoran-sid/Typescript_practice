## 方案一：按“模型—边界验证—状态渲染”三层组合

### 搭建顺序

1. 先声明任务状态、任务实体和导入结果的判别联合。
2. 从最小的 record 检查开始，再完成状态、单个任务和任务数组的 TODO 验证。
3. 让导入函数统一处理 JSON 语法失败与结构失败，成功后再交给状态说明函数。

### 类型与数据流

JSON 文本 → `unknown` → 分层类型守卫 → `ImportResult` → 状态收窄 → 展示文字。

### 关键自检点

- 解析成功不代表数据形状正确；嵌套状态也必须逐字段验证。
- 失败分支不得携带伪造任务，状态渲染必须穷尽所有成员。
