# Day 07 参考答案说明

## 01 `map` 的返回值

`map` 会收集每次回调的返回值。答案返回 `price * 2`，因此得到长度相同的新数组。

## 02 `filter` 的布尔条件

偶数除以 2 的余数是 0，所以条件是 `value % 2 === 0`。

## 03 `find` 的条件与缺失情况

查找条件改为 `user.id === 3`。保留 `undefined` 检查很重要：把数据改掉后，程序仍不会崩溃。

## 04 多步数组处理

先筛选完成订单，再映射编号，最后循环累计金额。拆成中间变量比初学阶段写一条超长链更容易调试。

```powershell
npm run beginner:solution -- day07 04
```
