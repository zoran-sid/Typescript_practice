# Day 03 参考答案说明

`studyMinutes` 是 `number[]`。两个统计变量会在循环中变化，因此使用 `let` 并从 0 开始。

每一轮 `for...of` 都把一个元素交给 `minutes`。累加语句同时使用旧的 `totalMinutes` 和当前 `minutes`，所以结果依次变为 30、75、135、155。

最长记录只在当前值更大时更新，依次变为 30、45、60，最后的 20 不满足条件，因此结果仍是 60。`studyMinutes.length` 直接给出项目数量 4，数组改变时不需要手工改输出。

## 拓展思考参考方向

当所有数据都小于 0 时，以 0 作为“当前最大值”会让任何真实数据都无法胜出，最后错误地保留并不存在于数组中的 0。数组确认非空时，可以从第一项初始化最大值，再处理其余元素；以后学习缺失值时还会讨论空数组该怎样处理。
